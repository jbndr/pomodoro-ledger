Push stays off until you set three Worker secrets once. After the PR is merged and deployed, run `npm run vapid` in the repo. It prints a public and a private key. Then run `npx wrangler secret put VAPID_PUBLIC_KEY` and paste the public key, `npx wrangler secret put VAPID_PRIVATE_KEY` and paste the private key, and `npx wrangler secret put VAPID_SUBJECT` with a contact such as mailto:you@example.com. You don't need to redeploy. Never commit the private key. Until the secrets are set, Remind me only works while a tab is open, as it does today.
